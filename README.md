# VvokAI

Бот для Brawl Stars, который **уворачивается от снарядов**, **стреляет с упреждением** и **двигается как человек**.

Форк [PylaAI](https://github.com/PylaAI/PylaAI). Оригинал выполнял полторы функции из трёх: ходил, стрелял автоприцелом и никак не реагировал на летящие в него снаряды. Здесь добавлены недостающие полторы.

**Telegram: [@nyavke](https://t.me/nyavke)**

## Чем отличается от оригинала

| Функция | PylaAI | VvokAI |
|---|---|---|
| Уворот от снарядов | нет | детект + предсказание траекторий + выбор направления |
| Атака | автоприцел (бьёт где враг **был**) | решение уравнения перехвата |
| Движение | рывками по 8 направлениям | плавное скольжение, резкое только в уворот |
| Границы карты | не определяются | измеряются по поведению камеры |
| Выбор цели | ближайший | тот, кого можно добить |
| Простой | стоит рядом с AFK-союзником до конца матча | через 5 секунд уходит к центру |
| Тесты | нет | 79 проверок, `tests\run.py` |

## Установка

Нужен [Python 3.11.9](https://www.python.org/downloads/release/python-3119/).

Распакуй архив и **запусти `start_pyla.bat` двойным щелчком**. Лаунчер сам создаст venv, поставит зависимости и откроет веб-интерфейс.

Если запускаешь из терминала, то в PowerShell обязательно с `.\` впереди:

```
.\start_pyla.bat
```

Без точки со слэшем PowerShell отвечает `Имя "start_pyla.bat" не распознано как имя командлета` — он не ищет команды в текущей папке. В `cmd.exe` работает и без неё.

### CUDA

Если у тебя NVIDIA, поставь CUDA-сборку onnxruntime — это ускоряет распознавание в 3.7 раза (5.6 мс против 20.8 мс на RTX 3080 Ti):

```sh
venv\Scripts\python.exe -m pip install "onnxruntime-gpu[cuda,cudnn]==1.28.0"
venv\Scripts\python.exe -m pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu
```

Вторая строка обязательна: CUDA-сборка PyTorch везёт **свой** набор cuDNN, который конфликтует с onnxruntime. В боте torch нужен ровно для одной строки, поэтому CPU-версии достаточно.


## Вход в панель

При первом запуске панель просит придумать **имя пользователя и пароль**. Без них она не открывается: через неё запускается и останавливается бот, правится очередь, а на странице настроек виден API-токен.

Учётка лежит только на твоей машине, в `cfg/panel_auth.toml`, и пароль там не хранится — только PBKDF2-хеш с солью. Забыл пароль — удали этот файл, панель снова предложит завести новый.

Входа с `127.0.0.1` без пароля намеренно нет: туннели подключаются к локальному интерфейсу, и запрос через туннель выглядит локальным. Исключение для localhost открыло бы панель наружу при первом же пробросе порта.

## Доступ снаружи

**Настраивать ничего не надо.** `start_pyla.bat` сам поставит `cloudflared` (через winget, а если его нет — скачает программу) и включит доступ. Панель станет доступна по HTTPS-адресу откуда угодно, а не только из домашней сети.

Не хочешь — поставь в [cfg/general_config.toml](cfg/general_config.toml):

```
remote_access = "off"
```

Установщик это уважает и обратно не включит.

Открыть панель без логина всё равно нельзя, а завести аккаунт можно только с самого компьютера или из его сети — так что адрес, попавший в чужие руки, даёт лишь форму входа.

При старте бот поднимет туннель и `/panel` начнёт присылать адрес вида `https://что-то.trycloudflare.com`. HTTPS до самой машины, роутер трогать не надо, работает даже за CGNAT — туннель звонит наружу сам.

### Если адрес отдаёт Cloudflare Error 1033

Значит `cloudflared` запустился, но до Cloudflare не достучался. Ему нужен **исходящий порт 7844** (TCP и UDP), и чаще всего его съедает VPN или прокси на самой машине — они перехватывают соединение, и туннель молча не поднимается.

Бот теперь это ловит сам: если соединение не установилось, адрес не публикуется, а в консоль и в `/panel` попадает диагностика самого cloudflared с номером порта. Пробует оба протокола, `quic` и `http2`.

Что делать: выключить VPN, либо исключить в нём `argotunnel.com` и порт 7844 из перехвата. Локальный адрес по Wi-Fi работает в любом случае.

Что защищает панель на публичном адресе:

- **Вход обязателен**, как и в сети.
- **Перебор пароля притормаживается**: 5 попыток свободно, дальше пауза 30 с и удвоение до 15 минут.
- **Создать первый аккаунт можно только со своей сети.** Иначе учётку завёл бы тот, кто первым откроет ссылку.
- **Туннель не поднимется, пока аккаунта нет.** Через туннель все запросы выглядят локальными, так что эти две проверки работают только вместе.

**Адрес меняется при каждом перезапуске бота** — ссылка из вчерашнего сообщения отдаст ошибку Cloudflare 1033. Спрашивай `/panel` заново, а не переоткрывай старую. Показывать адрес никому не стоит. `cloudflared` намеренно не качается сам — программу, которая выставляет твою машину в интернет, ставишь ты, а не апдейтер.

## Управление с телефона

Телеграм раньше умел только присылать уведомления. Теперь он принимает команды:

```
/panel  /help
```

Всё остальное делается в панели, а телеграм нужен, чтобы в неё попасть: `/panel` присылает ссылку (вход по логину, см. выше) — открывается с телефона, **если он в той же Wi-Fi сети**, что и компьютер. Из мобильного интернета не откроется — панель слушает только твою сеть. В Discord остались все команды целиком: `/start`, `/stop`, `/pause`, `/status`, `/screenshot`, `/queue`, `/restart_game` (там он зарегистрирован как `/restart_brawl_stars`) и `/panel`. Если пробрасывать её наружу туннелем, логин теперь хотя бы есть, но адрес всё равно лучше никому не показывать.

Нужны те же два значения, что и для уведомлений — `telegram_token` и `telegram_chat_id` в [cfg/webhook_config.toml](cfg/webhook_config.toml). Если они уже стоят, команды заработают сами после перезапуска.

Команды принимаются **только** из чата с указанным `telegram_chat_id`. Токен бота — единственный секрет здесь, и любой, у кого он есть, может боту написать.

## Уворот

Как это устроено и почему не тонет в шуме — подробно в **[DODGE.md](DODGE.md)**.

Коротко: камера в Brawl Stars едет за игроком, поэтому при ходьбе весь фон выглядит как движение — на этом ломаются наивные детекторы. Здесь шум режут пять независимых фильтров: компенсация сдвига камеры по четырём патчам, трёхкадровая разность, палитра карты, происхождение от бокса врага и проверка прямолинейности.

Замер на синтетическом стенде: **0 ложных срабатываний** при панорамировании камеры, ошибка скорости 0.2%, задержка обнаружения 100 мс, 3.3 мс на кадр.

### Настройка

Всё в [cfg/dodge_config.toml](cfg/dodge_config.toml), каждый параметр с объяснением. Главные:

| Параметр | Смысл |
|---|---|
| `reaction_latency` | компенсация задержки видеопотока — **самый важный** |
| `motion_threshold` | чувствительность детектора |
| `max_turn_rate` | резкость поворотов при обычной ходьбе |
| `HOLD_RANGE_NEAR/FAR` | дистанция боя (в шапке плейстайла) |

### Инструменты

```sh
venv\Scripts\python.exe tools\dodge_report.py --detail
```

Разбирает лог и говорит, **почему** по боту попали: не увидел вовремя, не было выхода, упёрся в стену или тактика перевесила. Каждый вердикт лечится по-своему.

```sh
venv\Scripts\python.exe tools\dodge_tune.py запись.mp4 --sweep vision.motion_threshold=8,12,16,20
```

Прогоняет детектор по записи и печатает таблицу «шум против сигнала»  можно подобрать порог по данным, а не на глаз.

## Здоровье

Что бот теперь делает: уходит из боя ниже 32%, перестаёт сближаться ниже 55%,
дожимает раненого врага и стреляет в того, кого можно добить, а не в ближайшего.
Если полоску прочитать не удалось — значение `None`, и вся тактика откатывается
к прежней, дистанционной. «Не прочитал» никогда не означает «полное здоровье».

Настройки — секция `[health]` в [cfg/dodge_config.toml](cfg/dodge_config.toml),
выключается одной строкой. Каждое измерение рисуется в отладочном окне: рамка
вокруг найденной полоски и процент рядом. Пиксельная эвристика, на которую бот
опирается, но которую нельзя проверить глазами, хуже, чем её отсутствие.

## Токен Brawl Stars API и смена IP

Supercell привязывает токен к адресу, с которого он создан. Провайдер выдал
новый — токен мёртв, а API отвечает голым 403, из-за чего интерфейс раньше
показывал «неверный тег игрока» и отправлял искать несуществующую проблему.

Заполните `brawl_api_email` и
`brawl_api_password`. При 403 бот сам зайдёт в портал, удалит свой прошлый
ключ, выпустит новый под текущий адрес и повторит запрос — примерно две
секунды, один раз на смену адреса. Адрес берётся из самого отказа API, а не у
стороннего сервиса: API сообщает, с какого адреса он видит запрос, и это
единственное надёжное число.

Удаляются только ключи, помеченные `managed-by-vvokai`, так что созданное
руками не трогается.

Пароль в текстовом файле остаётся паролем в текстовом файле. Он никуда не
уходит, кроме сайта Supercell, и не пишется в логи. Если это не устраивает,
остаётся вариант с прокси: выпустить ключ на постоянный адрес прокси и ходить
через него. В форке этого пока нет.

**Чего не вылечит ничто.** Если соединение выходит каждый раз с нового адреса —
VPN с ротацией, мобильный интернет, — ключ на один адрес не догонит его в
принципе. Бот это распознаёт, прекращает попытки после двух неудач и говорит об
этом прямо, вместо того чтобы бесконечно долбить портал.

## Тесты

```sh
venv\Scripts\python.exe tests\run.py
```

151 проверка: непрерывность треков снарядов на разных скоростях и частотах кадров,
точность чтения полосок здоровья и отсутствие ложных срабатываний на траве,
тактические решения плейстайла и то, что все имена в нём разрешаются — песочница
`.pyla` не имеет встроенных функций, поэтому пропавший ключ контекста это не
ошибка при старте, а NameError посреди матча.

## Плейстайл

`playstyles/unified_dodge.pyla` объединяет все четыре официальных плейстайла (боевое дерево, следование за союзниками, ротация к центру, архетипы) и добавляет уворот.

Вся тактика  в одном файле, настройки в шапке. Движок даёт только «глаза»: список снарядов, скорости врагов, границы карты.
